What it does

One app, five kinds of work

You create backend profiles. Each binds a model to a set of capabilities, and the app gives it somewhere to run.

Devgentic Illustration
Five profile types

Pick the shape of the work

Every profile binds a model to instructions and capabilities. Choose the one that fits the job.

  • Bot — plain chat with a model, instructions and optional knowledge sources.
  • Agent — a tool-using loop with optional planning and self-reflection.
  • Workflow — a node graph with routers, approval gates, triggers and actions.
  • Image Generator and Code — text-to-image, and a project-scoped agent for reading and editing a codebase.

Beyond the main window

Orb and QuickAccess

Orb is a floating voice orb with wake-word or push-to-talk activation that speaks its answers back. QuickAccess is a global-hotkey panel you can summon from any app.

  • Opt-in: Orb stays off until you turn it on.
  • Wake word or push-to-talk, and spoken replies.
  • QuickAccess opens from a global hotkey, in whatever app you are using.

Unattended and remote

Scheduler and chat bridges

Run profiles on a cron schedule without opening the app, and reach them from Slack, Discord or Telegram.

  • A cron scheduler for unattended runs.
  • Remote bridges for Slack, Discord and Telegram, with approvals handled in chat.
  • Bridges are yours to configure: the app has no hosted service in the middle.

Seven backends

You choose where inference runs

MLX and Ollama run on your Mac. OpenAI, Anthropic, Google, OpenRouter and any OpenAI-compatible endpoint run remotely. MLX models are browsed and downloaded in-app from the Hugging Face Hub.

  Local profile (MLX, Ollama) Cloud profile
Where requests go Nowhere — inference stays on this Mac To the provider you configured
Offline Yes, once the model is downloaded Needs an internet connection
Cost No per-token fees; uses your hardware Billed by the provider, with your own key
Telemetry from Devgentic None None

A cloud profile sends its requests to the provider you configured — that is what a cloud profile is. See the privacy statement for exactly what leaves your Mac and when.

Before you use it

Built to be approved, not blindly trusted

Devgentic is pre-release software that drives shell commands, edits files and automates the UI on your machine, with your user's privileges.

Not sandboxed

The app is deliberately outside the App Sandbox so tools can do real work. It is signed with the hardened runtime.

Approval system

Tool calls can require your approval by risk tier. Read what a tool is asking to do before approving it.

Autonomous mode

Be deliberate about turning it on. It lets an agent act without asking each time.

Security policy

SECURITY.md spells out what counts as a vulnerability in a tool built on this trust model, and where to report one.

Requirements

What you need

macOS

macOS 26.1 or later.

Processor

Apple Silicon (arm64). There is no Intel build.

Memory & disk

Local models need roughly their own size in memory and disk, so it depends on what you download. Cloud profiles need none.

Dependencies

None to install. The project uses Swift Package Manager only.
